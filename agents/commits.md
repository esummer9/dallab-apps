# Git 커밋 메시지 규약 (Conventional Commits)

본 문서는 DALLAB 프로젝트 및 연계 프로젝트에서 일관되고 명확한 커밋 이력을 유지하기 위해 사용하는 **Git 커밋 메시지 규약** 가이드입니다. 에이전트 및 개발자는 커밋 메시지 작성 시 본 규약을 준수합니다.

- **웹 문서 URI**: [https://apps.dallab.kr/agents/commits/](https://apps.dallab.kr/agents/commits/)

> [!IMPORTANT]
> **개발자 컨펌 필수 원칙**  
> AI 에이전트는 변경 사항에 대해 Git 커밋(`git commit`)을 직접 실행하기 전, 작성한 커밋 메시지를 개발자에게 먼저 제시하고 **항상 개발자의 사전 확인 및 최종 컨펌(승인)을 받은 후에만** 커밋을 수행해야 합니다.

---

## 1. 커밋 태그(Type) 목록

| 태그 | 의미 |
| :--- | :--- |
| `init` | 초기화 |
| `feat` | 새로운 기능 추가 |
| `fix` | 버그 수정 |
| `style` | 코드 포맷 변경, 세미콜론 누락 등 (코드 로직 변경 없음) |
| `refactor` | 코드 리팩토링 (기능 변화 없이 코드 구조 개선) |
| `test` | 테스트 코드 추가 및 리팩토링 |
| `chore` | 빌드 업무, 패키지 매니저 설정 등 기타 작업 |
| `perf` | 성능 개선 |
| `docs` | README.md 수정, 새로운 도움말 .md 파일 추가, API 문서 업데이트, 코드 내 주석 추가 등 |

---

## 2. 태그 예시 및 판단 기준

- **시스템에 기능을 더하는 메시지** ➔ `feat`
- **설명이나 주석 목적의 메시지** ➔ `docs`
- **운영 관리를 위한 설정/기타 작업** ➔ `chore`
- **코드의 로직에 영향을 주지 않고, 개발자나 운영자가 참고하기 위한 주석(Comment)이나 설명 문구만 추가한 것** ➔ `docs`

---

## 3. 커밋 메시지 기본 구조

```text
<태그> (<기능, 메뉴, 카테고리>): <작업 내용>

[본문 (선택 사항)]

[꼬리말 (선택 사항)]
```

### 작성 규칙
1. **기본 형식**: `<태그> (<기능, 메뉴, 카테고리>): <작업 내용>` 형태를 따릅니다.
   - 예시: `test (기능, 메뉴, 카테고리): 공휴일 API 응답 파싱 단위 테스트 추가`
2. **태그(Tag/Type)**: 소문자로 작성합니다. (`feat`, `fix`, `docs`, `test`, `chore` 등)
3. **대상 범위(Scope)**: 괄호 안에 변경 대상이 되는 **기능, 메뉴, 카테고리, 화면, 모듈명**을 명시합니다.
4. **구분자 및 제목**: 괄호 뒤 콜론(`:`)과 공백 한 칸을 두고, 무엇을 변경했는지 50자 이내로 명확하게 서술합니다. (제목 끝 마침표는 생략)
5. **본문(Body)**: 필요한 경우 무엇을, 왜 변경했는지 줄바꿈 후 자세히 설명합니다.
6. **개발자 컨펌 필수**: 커밋 명령 실행 전, 확정할 커밋 메시지를 개발자에게 사전에 보여주고 항상 확인 및 컨펌을 받습니다.

---

## 4. 실전 작성 예시

### `feat` (기능 추가)
```text
feat (저항 계산기): 5밴드 색상 코드 계산 기능 추가
```

### `fix` (버그 수정)
```text
fix (음력 달력): 윤달 계산 시 날짜 밀림 현상 수정
```

### `docs` (문서 및 주석)
```text
docs (가이드): README.md에 에이전트 커밋 규약 링크 추가
```
```text
docs (개인정보처리방침): 오믹스 v1.1 개인정보 처리방침 문서 추가
```

### `chore` (설정 및 빌드)
```text
chore (CI/CD): Jekyll GitHub Actions 배포 워크플로우 설정 갱신
```

### `refactor` (리팩토링)
```text
refactor (날짜 유틸): 날짜 계산 유틸 함수 모듈화 분리
```

### `style` (코드 스타일)
```text
style (에디터): 코드 들여쓰기 및 세미콜론 누락 수정
```

### `test` (테스트)
```text
test (기능, 메뉴, 카테고리): 공휴일 API 응답 파싱 단위 테스트 추가
```
```text
test (달력 계산): 양력-음력 변환 로직 단위 테스트 추가
```
