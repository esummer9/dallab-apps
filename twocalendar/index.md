# twocalendar 개인정보 처리방침

**ediapp**(이하 "개발자")은 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」, 「개인정보 보호법」 등 관련 법령을 준수하며, **twocalendar**(이하 "앱") 이용자의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 다음과 같이 개인정보 처리방침을 수립·공개합니다.

---

## 1. 수집하는 개인정보 항목 및 수집 방법

본 앱은 회원가입 절차 없이 사용할 수 있는 비회원제 서비스입니다. 기본적으로 사용자의 개인정보를 서버로 자동 수집하거나 저장하지 않으며, 서비스 제공을 위해 최소한의 정보만을 이용합니다.

### 1) 사용자가 직접 입력하는 정보 (기기 내부 저장)
- **개인 일정 정보**: 일정 제목, 날짜, 시간, 메모/설명 등
- **기념일 및 생일 정보**: 이름, 약칭, 날짜(양력/음력 구분), 메모 등
- **저장 위치**: 이용자의 기기 내부 SQLite 데이터베이스(`ediapp2.db`)에만 저장되며, 외부 서버로 자동 전송되지 않습니다.

### 2) 백업 및 복원 시 수집/전송되는 정보 (사용자 동의 및 요청 시)
- **백업 데이터**: 사용자가 직접 백업한 개인 일정 및 기념일 데이터 (JSON/ZIP 형태)
- **식별 코드**: 랜덤코드, 사용자가 지정한 백업코드
- **저장 위치**: Google Firebase Storage 및 Firebase Firestore
- **처리 목적**: 다른 기기로의 데이터 이전 또는 앱 재설치 시 복원 기능 제공

### 3) 서비스 이용 과정에서 자동으로 수집되는 정보 (제3자 SDK)
- **광고 제공 (Google AdMob)**:
  - 수집 항목: 광고 ID(GAID/IDFA), IP 주소, 기기 정보(모델명, OS 버전), 앱 이용 통계 및 진단 정보
  - 처리 목적: 맞춤형/비맞춤형 광고 게재 및 광고 효과 분석

---

## 2. 개인정보의 이용 목적

개발자는 수집한 정보를 다음의 목적을 위해서만 이용합니다.

1. **달력 및 일정/기념일 관리 기능 제공**: 양력/음력 달력 조회, 음/양력 변환, 개인 일정 기록, 기념일 계산
2. **알림 서비스 제공**: 공휴일, 개인 일정, 기념일 사전 알림 (POST_NOTIFICATIONS 권한 사용)
3. **데이터 백업 및 복원**: 이용자의 요청에 의한 백업 파일 업로드 및 복원 다운로드
4. **일정 및 기념일 공유**: QR 코드 생성 및 스캔을 통한 사용자 간 일정/기념일 간편 공유
5. **광고 게재**: 앱 내 구글 AdMob 광고 표시

---

## 3. 앱 접근 권한 안내

앱 서비스 제공을 위해 다음과 같은 기기 접근 권한을 요청합니다. 각 권한은 해당 기능을 사용할 때 이용자가 선택적으로 허용할 수 있습니다.

| 권한 명칭 | 접근 목적 | 필수/선택 |
| :--- | :--- | :--- |
| `INTERNET` | 공공데이터 공휴일/음양력 정보 수신, Firebase 백업/복원, AdMob 광고 로드 | 필수 |
| `CAMERA` | QR 코드를 스캔하여 일정 및 기념일 데이터를 가져오기 위한 목적 | 선택 |
| `POST_NOTIFICATIONS` | 등록된 일정, 기념일, 공휴일 알림을 수신하기 위한 목적 | 선택 |
| `READ_CALENDAR` / `WRITE_CALENDAR` | 기기 내부 캘린더와의 일정 연동 및 생성 | 선택 |
| `MediaStore (외부 저장소)` | 백업 정보(랜덤/백업코드)를 이미지 형태로 기기 갤러리에 저장하기 위한 목적 | 선택 |

> [!NOTE]
> 선택적 접근 권한은 허용하지 않더라도 해당 기능을 제외한 기본 달력 서비스는 이용할 수 있습니다.

## 4. 개인정보의 제3자 제공 및 위탁

개발자는 이용자의 개인정보를 원칙적으로 외부에 제공하지 않습니다. 다만, 서비스 운영 및 제공을 위해 아래와 같은 외부 전문업체의 서비스(SDK)를 활용하고 있습니다.

### 1) 제3자 서비스 제공자 (SDK)

- **Google Cloud / Firebase (Google LLC)**
  - **목적**: 이용자 요청 시 백업 데이터(압축 파일) 및 백업 로그 저장
  - **수집/제공 항목**: 백업 파일(JSON/ZIP), 랜덤코드, 백업코드, 기기 진단 정보
  - **개인정보 처리방침**: [Google 개인정보 처리방침](https://policies.google.com/privacy)

- **Google AdMob (Google LLC)**
  - **목적**: 앱 내 광고 게재 및 분석
  - **수집/제공 항목**: 광고 ID, IP 주소, 기기 상태 및 통계 데이터
  - **개인정보 처리방침**: [Google AdMob 개인정보 처리방침](https://policies.google.com/privacy)

- **공공데이터포럼 (한국지능정보사회진흥원 등)**
  - **목적**: 공휴일 정보 및 음/양력 변환 API 조회
  - **수집/제공 항목**: 없음 (API 요청 시 연도/월/일 매라미터만 전송되며 개인정보는 포함되지 않음)

## 5. 개인정보의 보유 및 파기 절차

### 1) 기기 내 저장 데이터
- 앱 내에서 이용자가 일정을 삭제하는 경우 해당 데이터는 즉시 삭제됩니다.
- 이용자가 앱을 삭제(언인스톨)하는 경우 기기 내 저장된 모든 데이터(`ediapp2.db`)는 즉시 파기됩니다.

### 2) 백업 데이터 (Firebase Storage / Firestore)
- 이용자가 백업한 데이터는 만료일(기본 5일 등 설정값)이 지나거나 새로운 백업 데이터로 갱신 시 파기됩니다.
- 이용자는 백업 시 사용한 랜덤코드와 백업코드가 유출되지 않도록 직접 관리할 책임을 집니다.

---

## 6. 이용자의 권리와 행사 방법

1. **데이터 조회, 수정, 삭제**: 앱 내 달력, 개인일정, 기념일 화면에서 언제든지 본인의 데이터를 직접 조회, 수정, 삭제할 수 있습니다.
2. **앱 접근 권한 철회**: 이용자는 스마트폰의 설정 메뉴에서 앱 권한을 직접 변경하거나 철회할 수 있습니다.
   - *설정 > 애플리케이션 > twocalendar > 권한* 에서 각 권한별 허용/거부 설정 가능
3. **데이터 전체 파기**: 앱을 삭제(언인스톨)하면 기기에 저장된 모든 정보가 완전히 삭제됩니다.
